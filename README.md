# Sumanth Golla — Portfolio

A complete responsive portfolio made with plain HTML, CSS and JavaScript.

## Run locally

1. Unzip the folder.
2. Double-click `index.html` to open it in a browser.
3. Or open the folder in VS Code and use Live Server.

No build commands, npm packages or backend are required. Google Fonts are optional; system fonts work offline.

## Edit

- `index.html`: text, project details, email, links.
- `style.css`: colors, spacing, layout and mobile styles.
- `script.js`: mobile navigation, animations and active section links.
- `assets/Sumanth_Golla_Resume.pdf`: downloadable resume.
